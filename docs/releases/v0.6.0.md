What changed since 0.5.3 is the signed in-app extension catalog in Settings › Extensions and three Rust dependency security updates (`cookie`, `url`, `rustix`). These scenarios check catalog loading and offline fallback, local search and filtering, install consent and cancel, and that existing installed extensions keep working.

| # | Scenario (rule) | Steps, with real input | Expected | Result |
| --- | --- | --- | --- | --- |
| 1 | Browse catalog loads, verifies signature, and falls back to saved cache when offline (extension catalog, #251, #252) | Open **Settings › Extensions** and click **Browse**. Wait for the catalog to load, then click **Refresh**. Disconnect the Mac from the network, close and reopen Settings › Extensions › Browse, and click **Refresh**. | Online: the catalog loads from `https://quentinbest.github.io/Linen/catalog/v1/catalog.json` with extension titles, publishers, descriptions, and **Get** / **Installed** actions, with no verification error. Offline: Linen shows the offline banner ("You’re offline. Showing the saved catalog.") and keeps listing the cached catalog entries. | |
| 2 | Local search and category filtering narrow the catalog without network requests (extension catalog, #251) | In **Settings › Extensions › Browse**, click in the **Search extensions** field and type part of an extension name or description. Click through the category pills (**All**, **Lookup**, **Theme**, **Export**, **Navigation**, **Utility**). Type a string that matches nothing, then clear the search box. | The list filters immediately as you type and as you switch categories. A non-matching query shows "No extensions match your search." Clearing the search restores the full list for the selected category. | |
| 3 | Consent-sheet install and cancel match local `.linenext` installs (extension catalog, #251; Screen 11) | Click **Get** on an uninstalled extension in **Browse**. When the permission consent sheet opens, inspect the listed permissions and allowed hosts, then click **Cancel**. On confirm: the package downloads, verifies its checksum, installs cleanly, switches to **Installed** in **Browse**, and appears in the **Installed** tab. | |
| 4 | Existing installed extensions stay intact and usable after upgrading from 0.5.3 (regression check; Screen 11, LK6) | Switch to **Settings › Extensions › Installed**. Check previously installed extensions (such as Explain), toggle one off and back on, open its **Options…** if it has one, and trigger its action in an open book. | Every previously installed extension is still listed with its existing enabled state and allowed hosts. Toggling, Options, and in-book actions work as before with no errors. | |
